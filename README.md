# BookShell Builder

একটি Android অ্যাপ (`builder`) যা এক বা একাধিক PDF / EPUB / URL থেকে **বাস্তব বইয়ের মতো পেজ-ওল্টানো** সাইন করা APK (`template`) বানায়।
পদ্ধতি WebShell Builder-এর মতোই: টেমপ্লেট APK-এর বাইনারি ম্যানিফেস্ট প্যাচ করে বই, কভার, কনফিগ ঢুকিয়ে `apksig` দিয়ে সাইন করা হয়।

## বিল্ড
1. Android Studio (JDK 17) দিয়ে খুলুন, অথবা GitHub-এ push করলে `.github/workflows/android.yml` debug + release APK বানাবে।
2. `./gradlew :builder:assembleDebug` → `builder/build/outputs/apk/debug/`। ফোনে ইনস্টল করুন।

## ফিচার
| # | ফিচার | কীভাবে |
|---|---|---|
| ১ | একাধিক PDF → একটি বই | একই বইয়ে একাধিক ফাইল যোগ করুন; রিডার সেগুলো ক্রমানুসারে একটানা পেজ হিসেবে পড়ে (ফাইল মার্জ হয় না, তাই দ্রুত ও নিরাপদ)। PDF ও EPUB মিশিয়েও দেওয়া যায় |
| ২ | URL থেকে | "+ URL"; APK তৈরির সময় ডাউনলোড হয়ে অ্যাপের ভেতরে ঢোকে (Google Drive/Dropbox শেয়ার লিংক সরাসরি লিংকে রূপান্তর হয়; ওয়েব পেজ এলে ব্যর্থ বলে জানায়) |
| ৩ | স্প্ল্যাশ | কাস্টম ছবি, অথবা প্রথম বইয়ের প্রথম পেজ/EPUB কভার; ফুল স্ক্রিন ফিট/ক্রপ/স্ট্রেচ বা লোগো সাইজ |
| ৪ | বাস্তব পেজ ওল্টানো | ডান→বামে টানলে সামনে, বাম→ডানে পিছনে; কাগজ ভাঁজ হয়, উল্টো পিঠ ও ছায়া দেখা যায়। ল্যান্ডস্কেপে দুই পেজ (কভার একা ডানে), পোর্ট্রেটে এক পেজ। পোর্ট্রেটে ভার্টিক্যাল, ল্যান্ডস্কেপে হরিজন্টাল স্ক্রল বার। পাশে ট্যাপ বা ভলিউম বাটনেও ওল্টানো যায় |
| ৫ | লাইব্রেরি | একাধিক বই যোগ করলে কভারসহ তালিকা; শেষ পড়া পেজ মনে থাকে |
| ৬ | EPUB | নিজস্ব পেজিনেশন (লেখা + ছবি), A+/A− ফন্ট সাইজ |
| ৮ | জুম | পিঞ্চ বা ডাবল-ট্যাপ |
| ৭ | About | শিরোনাম, বিবরণ, নাম, লিংক বাটন |

## সীমাবদ্ধতা
- জুম: দুই আঙুলে পিঞ্চ বা মাঝখানে ডাবল-ট্যাপ (সর্বোচ্চ ৪x)। জুম অবস্থায় এক আঙুলে পেজ সরে, পেজ ওল্টে না; ডাবল-ট্যাপে বা পেজ বদলালে জুম আউট। জুমে পেজ বেশি রেজোলিউশনে আবার রেন্ডার হয় (মেমরি সীমায় ৩২MB/পেজ)।
- EPUB: Android-এর `Html` দিয়ে রেন্ডার হয়, তাই CSS (ফন্ট, টেবিল লেআউট, ফ্লোট) প্রায় অগ্রাহ্য; সাধারণ উপন্যাস/বইয়ের জন্য ঠিক আছে। DRM-যুক্ত EPUB/পাসওয়ার্ড দেওয়া PDF খুলবে না।
- বই APK-র ভেতরে থাকে, তাই বড় PDF মানে বড় APK; প্রথমবার খোলার সময় ফাইল অ্যাপের স্টোরেজে কপি হয়।
- সাইনিং কী প্রতি প্যাকেজ নেমে একবার তৈরি হয়; Builder আনইনস্টল করলে হারাবে।
- লেখকের অনুমতি/কপিরাইটের দায় আপনার।
